How EventHub works

A medium-complexity event ticketing and venue access flow.

🔎

1. Discover

Users browse events and filter them by category, city and price.

📄

2. View details

Users see date, time, venue, price and event information before booking.

💺

3. Select seats

Available and booked seats are displayed clearly so users can choose their seats.

💳

4. Confirm booking

Customer details are submitted and a booking ID is generated.

🎟️

5. Digital ticket

The ticket contains booking details, selected seats and an access code.

🚪

6. Venue access

At the venue, the ticket can be scanned or validated against the booking.

Project architecture

Keep the frontend simple and connect it to your microservices backend.

Browser UI → API layer → Event Service / Booking Service / Venue Access Service

This UI intentionally keeps the frontend independent from the backend implementation. Only the API functions in js/api.js need to be mapped to your Spring Boot endpoints.
