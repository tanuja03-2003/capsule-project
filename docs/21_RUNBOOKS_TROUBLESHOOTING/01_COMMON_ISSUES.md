# Common Issues

Use this format:

## Pod is CrashLoopBackOff
Symptoms:
Diagnosis:
Commands:
Root causes:
Fix:
Verification:
Rollback:

## Service cannot reach another service
Check:
- Service exists
- Endpoints exist
- DNS resolves
- Port is correct
- NetworkPolicy
- Application bind address

## Kafka consumer lag is increasing
Check:
- Consumer group
- Partition count
- Consumer health
- Processing latency
- KEDA configuration
