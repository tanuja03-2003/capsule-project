# Observability

Target stack:
- Prometheus: metrics
- Grafana: dashboards
- Loki: centralized logs
- OpenTelemetry: telemetry collection
- Tempo: distributed traces
- Alertmanager: alert routing

Golden signals:
- Latency
- Traffic
- Errors
- Saturation

Document important dashboards and alerts for:
- API Gateway
- Booking Service
- Payment Service
- Venue Access
- Kafka
- Redis
- Kubernetes nodes/pods
